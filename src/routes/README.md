# Routes

This app uses **TanStack Router file-based routing** (Vite SPA). Every `.tsx` file in this directory defines a route. The root layout is `src/routes/__root.tsx`.

`routeTree.gen.ts` is auto-generated. Don't edit it by hand.

| File | URL |
| --- | --- |
| `index.tsx` | `/` |
| `category.$slug.tsx` | `/category/:slug` |
| `product.$slug.tsx` | `/product/:slug` |
